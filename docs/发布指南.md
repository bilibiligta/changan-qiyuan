# 发布指南（自己推 GitHub 用）

两个仓库都已在本地准备好，**只差 `git remote add` + `git push`**。
下面命令都在 PowerShell 里跑（git 在 `D:\Program Files (x86)\Git\cmd\git.exe`，已配好 `user.name/email`）。

---

## 一、先推「集成」仓库

### 1. 在 GitHub 上建一个空仓库

- 名称建议：`changan-qiyuan`
- **不要**勾 Add README / Add .gitignore / Choose a license（本地都有了，勾了会冲突）
- 可见性：Public（HACS 必须公开）

### 2. 推送

```powershell
cd <你本地的仓库目录>   # 例如 D:\code\changan-qiyuan
git remote add origin https://github.com/<你的用户名>/changan-qiyuan.git
git branch -M main
git push -u origin main --tags
```

### 3. 打 Release（HACS 靠它识别版本）

GitHub 仓库页 → **Releases → Draft a new release**：

- **Choose a tag**：选 `v0.9.0`（本地已有这个 tag，push 时会一起上去）
- **Release title**：`v0.9.0`
- 描述：从 `CHANGELOG.md` 里拷 `v0.9.0` 那一段
- **不要**勾 `Set as a pre-release`，**不要**勾 `Set as latest release` 以外的怪选项
- 点 Publish

> HACS 判断「有新版本」= tag 形如 `v0.9.0` 且是正式 Release。
> 以后发版就三步：改 `manifest.json` 的 version → 改 CHANGELOG → 打 tag 并建 Release。

### 4. 补全仓库信息（建议）

仓库页右上 ⚙️ Settings 上方 **About**：

- Description：`长安启源（启源 A07）Home Assistant 集成：车况 + 远程控车`
- Topics：`home-assistant` `hacs` `changan` `qiyuan` `ev` `car`

## 二、再推「卡片」仓库

```powershell
cd <你本地的卡片仓库目录>
git remote add origin https://github.com/<你的用户名>/changan-qiyuan-card.git
git branch -M main
git push -u origin main --tags
```

同样建一个 Release（tag 选 `v0.3.3`）。

**建议补两张图**（HACS 前端列表会用到）：

- `preview.png`：卡片在仪表盘上的截图（放到仓库根目录，README 已引用）
- 可选 `preview-dark.png`

---

## 三、HACS 里怎么装（推完之后自己验证一遍）

1. HACS → 集成 → ⋮ → 自定义存储库 → 填 `https://github.com/<你的用户名>/changan-qiyuan` → 类别 Integration
2. 搜索「长安启源」→ 下载 → 重启
3. 检查 设置 → 设备与服务 → 添加集成 能不能搜到「长安启源」
4. 检查集成图标是否显示启源蓝标（来自 `custom_components/changan_qiyuan/brand/`）

卡片同理，类别选 **Lovelace**。

---

## 四、想进 HACS 默认商店（可选，进阶）

HACS 默认收录需要 PR：

1. 集成：给 [hacs/default](https://github.com/hacs/default) 提 PR，把仓库加到 `integration` 文件里
2. 前端：同一个仓库的 `plugin` 文件
3. 品牌图：给 [home-assistant/brands](https://github.com/home-assistant/brands) 提 PR（`custom_integrations/changan_qiyuan/`），这样 HACS 与 HA 商店里都能看到图标

默认收录有门槛（仓库要有一定 star、README 规范、CI 通过）。不着急的话先自己用自定义存储库装，完全一样能更新。

---

## 五、发布前自检清单

- [ ] `custom_components/changan_qiyuan/manifest.json` 里 `version` 与 tag 一致
- [ ] `CHANGELOG.md` 有对应版本的段落
- [ ] 没有把 token / 控车码 / 车架号 / 手机号 提交进仓库
  （自检：`git grep -nEi "eyJhbGci|LS[0-9A-Z]{15}|[0-9]{6}"` 只应命中文档里的占位说明）
- [ ] `hassfest` / `hacs` 两个 CI（`.github/workflows/validate.yml`）在 GitHub Actions 里变绿
- [ ] 真车验证过至少：读车况、开/关空调、锁车/解锁

---

## 六、以后怎么升级版本

```powershell
# 1. 改代码，改 manifest.json 的 "version"（比如 0.8.10）
# 2. 改 CHANGELOG.md，加一段
git add -A
git commit -m "feat: xxx"
git tag v0.9.1
git push origin main --tags
# 3. 在 GitHub 上用 v0.9.1 建 Release
```

HACS 里点「更新」→ 重启 HA 即可。
