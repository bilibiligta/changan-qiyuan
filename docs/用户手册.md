# 长安启源集成 · 用户手册

> 这份手册是写给**不写代码**的车主的。只需要照着点，就能在 Home Assistant 里看到自己的车、并且用手机控制它。
> 遇到这里没写的情况，先看最后的「出问题怎么办」。

---

## 1. 这个集成能帮你做什么

装好以后，你的 Home Assistant 里会多出一台「**长安启源 A07**」设备，它提供三类东西：

| 类型 | 举例 | 能干什么 |
| --- | --- | --- |
| **看**（传感器） | 剩余电量、续航、里程、四个轮胎胎压、车门有没有关好、车里温度、车停在哪 | 做仪表盘、做提醒、记录历史曲线 |
| **控**（开关/按钮） | 空调、座椅加热、哨兵、车门锁、后备箱、车窗留缝 | 点一下就远程执行，和在 App 里点一样 |

> **关于哨兵开关**：打开后车会先进入“已布防”，等车端准备好才变成“站岗中”（属性「哨兵状态」里能看到当前是哪一个）。
> 所以刚打开时看到“已布防待站岗”是正常的，不必重复点；开关显示为“开”就代表车端确实在布防了。
> 熄火久了车会深度休眠，这时开哨兵可能失败或超时，属正常现象。
| **联动**（自动化） | —— | 比如「电量低于 30% 就提醒我插枪」「晚上 10 点自动锁车检查」 |

它不修改你的车，也不装任何东西到车上——只是替你在云端调用长安 App 用的那套接口。

## 2. 准备工作

动手前确认三件事：

1. **Home Assistant 能正常用**（版本 2024.12 或更新）
2. **启源 App 能在你手机上正常登录**（记住登录用的手机号）
3. **知道你的控车码**：App 里「我的 → 安全设置 → 控车码」，6 位数字

> 控车码只用来做远程控车的安全校验。如果你只想「看车况」不控车，第 3 步可以先跳过（之后随时能补）。

## 3. 安装集成

### 情况 A：你装了 HACS（推荐，以后能一键升级）

1. 打开 HACS → 左侧「集成」
2. 右上角 **⋮** → 「**自定义存储库**」
3. 在「存储库」里粘贴本项目的 GitHub 地址
4. 「类别」选 **Integration** → 点「添加」
5. 回到 HACS，搜索「**长安启源**」→ 点进去 → 「下载」
6. **重启 Home Assistant**（设置 → 系统 → 右上角电源按钮 → 重启）

### 情况 B：没装 HACS（手动，一次性）

1. 在 GitHub 上点「Code → Download ZIP」，解压
2. 找到里面的 `custom_components/changan_qiyuan` 这个文件夹
3. 用 Samba / File Editor / WinSCP 之类的方式，把它整个复制到 HA 的
   `config/custom_components/` 下面
   最终路径应该是：`config/custom_components/changan_qiyuan/manifest.json`
4. **重启 Home Assistant**

---

## 4. 添加你的车

1. 打开 **设置 → 设备与服务**
2. 右下角「**添加集成**」
3. 搜索「**长安启源**」→ 点它
4. 按提示填写：

| 屏幕上的问题 | 你要填的 |
| --- | --- |
| 手机号 | 启源 App 登录用的手机号 |
| 短信验证码 | 点「发送验证码」，等手机上收到短信，填进去 |
| 控车码（可留空） | 6 位控车码；留空也能装，只是不能控车 |
| 是否保存控车码 | 建议选「是」，否则每次控车都要手动输入 |

5. 提交后等几秒，会出现「长安启源 A07」设备，下面挂着一堆实体

> **看不到实体？** 刷新一下浏览器（Ctrl+F5）。实体默认都是启用的，只有少数诊断类实体默认关闭（设置 → 设备与服务 → 实体 → 勾「显示已禁用实体」可以看到）。

## 5. 在仪表盘上用它

### 最简单的做法：直接加卡片

编辑仪表盘 → 添加卡片 → 按实体搜「剩余电量」，HA 会自动推荐一个仪表/历史曲线卡片。

### 更好看的做法：装配套车辆卡片

配套的「**长安启源 车辆卡片**」是另一个仓库，专门为这辆车画的界面（深色玻璃 + 车图背景 + 温度环 + 一键速冷速热）。

1. 下载卡片文件 `changan-qiyuan-card.js`，放到 `config/www/changan-qiyuan/` 下
2. **设置 → 仪表盘 → 右上角 ⋮ → 资源 → 添加资源**
   - URL: `/local/changan-qiyuan/changan-qiyuan-card.js`
   - 类型: **JavaScript 模块**
3. Ctrl+F5 强刷浏览器
4. 编辑仪表盘 → 添加卡片 → 搜「**长安启源**」

卡片里**必选**的三样（解锁、闭锁、空调）永远都在，其余（电量环、续航、里程、胎压、车内温湿度、座椅、哨兵、充电、位置）可以在卡片的可视化编辑器里**勾选**显示哪些。

## 6. 几个实用的自动化（可以直接抄）

### 6.1 电量低提醒

```yaml
alias: 电量低于 30% 提醒插枪
trigger:
  - platform: numeric_state
    entity_id: sensor.qi_yuan_a07_abc123_sheng_yu_dian_liang
    below: 30
action:
  - service: notify.mobile_app_你的手机
    data:
      message: >-
        电量只剩 {{ states('sensor.qi_yuan_a07_abc123_sheng_yu_dian_liang') }}%，
        记得插枪
```

### 6.2 回家前 10 分钟开空调

```yaml
alias: 快到家开空调
trigger:
  - platform: state
    entity_id: person.你
    to: home
    for: "00:10:00"
action:
  - service: climate.set_temperature
    target:
      entity_id: climate.qi_yuan_a07_abc123_kong_diao
    data:
      temperature: 24
  - service: climate.set_hvac_mode
    target:
      entity_id: climate.qi_yuan_a07_abc123_kong_diao
    data:
      hvac_mode: heat_cool
```

### 6.3 出门忘记锁车提醒

```yaml
alias: 车门未锁提醒
trigger:
  - platform: state
    entity_id: lock.qi_yuan_a07_abc123_che_men_suo
    to: unlocked
    for: "00:05:00"
action:
  - service: notify.mobile_app_你的手机
    data:
      message: 车已经解锁 5 分钟了，是不是忘了锁？
      data:
        actions:
          - action: LOCK_CAR
            title: 现在就锁
```

（想让它真的一键锁车，再配一个自动化，用 `lock.lock` 服务。）

## 7. 出问题怎么办

### 实体全变「不可用」

大概率是**登录过期**了。集成每 1 小时会自动续期一次；如果车好多天没开、refresh token 也过期，就需要：

**设置 → 设备与服务 → 长安启源 → 重新验证**，再走一遍短信验证码流程。

### 控车没反应，日志里有 1004 /「请输入校验码」

这是长安的风控，不是坏了。用开发者工具手动调两个服务：

1. `changan_qiyuan.send_control_sms`（会给你手机发短信）
2. `changan_qiyuan.authorize_control`，参数 `code: 收到的验证码`

之后一段时间内控车就不用再验证了。

### 空调点了没反应

- 车可能处于深度休眠（熄火很久没动），等 1~2 分钟再试一次
- 远程空调**默认 15 分钟自动关闭**，这是车端的逻辑，不是集成的问题

### 总里程显示「未知」

车端 T-BOX 的里程值溢出了（会返回 167 万公里，你的 App 里也一样）。集成把它当作无效值显示「未知」，等 T-BOX 恢复或去 4S 刷写就会正常。

### 还是不行，怎么排查

1. **设置 → 系统 → 日志**，搜 `changan_qiyuan`
2. 把报错原文连同时间点一起记下来
3. 到仓库的 Issues 里搜一下，或者提一个新的（**记得把 token、车架号、手机号打码**）

## 8. 名词对照

| 名词 | 什么意思 |
| --- | --- |
| 实体（Entity） | HA 里的一个「开关」「读数」对象，比如「剩余电量」 |
| 自动化（Automation） | 「如果……就……」的规则 |
| 服务（Service） | 让 HA 执行动作的指令，比如「锁车」 |
| HACS | HA 的社区插件商店 |
| 深度休眠 | 车熄火很久后，车上的通信模块睡着的状态 |

---

## 9. 安全提醒

- 控车码存在你自己的 HA 里，**不要**把它写进截图、Issues 或公开的自动化分享里
- 别人拿到你的 HA 就等于拿到你的车钥匙，请给 HA 加上强密码和 HTTPS
- 本集成是个人自用项目，与长安汽车无关；**远程控车有风险，请自行评估**
